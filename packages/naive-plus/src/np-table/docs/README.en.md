# np-table Table

A configuration-driven table that dynamically generates the table through `columns`, simple to use and highly extensible.

## Basic Usage

The table is dynamically generated by configuring `columns` through `option`, and data is fetched through `api.fetch`.

<demo src="../__demos__/basic.en.vue"></demo>

## Component Configuration

### Props

| Prop | Description | Type | Default |
| ------ | -------- | --------------------------- | ------ |
| option | Configuration | [TableOption](#tableoption) | -      |

### Methods

Get the table instance through `ref`, then call the following imperative methods. See [Imperative Methods](/en/table/expose/) for details.

| Method  | Description                                                                 | Type                  |
| ------- | --------------------------------------------------------------------------- | --------------------- |
| reload  | Reload the data, resetting to the first page                                | `() => Promise<void>` |
| refresh | Refresh the data of the current page                                        | `() => Promise<void>` |
| params  | Bound query params, passed to `api.fetch` as `queryParams`                  | `Record<string, any>` |

## Types

The component exports the following type definitions:

```ts
import type { TableOption, TableColumn, TableFilter, NpTableInst } from 'naive-plus'
```

### TableOption

| Prop | Description | Type | Default |
| ---------- | --------------------------------- | ------------------------------------------------------------------------------------ | ------ |
| columns    | Table columns                            | Array<[TableColumn](#tablecolumn)>                                                   | -      |
| api        | Data API                          | `{ fetch: (pageParams, otherParams) => Promise<{ items, itemCount? }> }`            | -      |
| props      | Table props, passed through to `n-data-table`. To prevent the table's internal vertical scroll from covering page content, scroll-related configs like `maxHeight`, `flexHeight`, and `virtualScroll` will be ignored | object                                                                               | -      |
| pagination | Pagination config; set to `false` to disable pagination | `false` / `PaginationConfig`                                                         | -      |
| filters    | Filter config                        | Array<[TableFilter](/en/table/filter/)>                                              | -      |
| slots      | Slot config, takes precedence over the same-named component slots | [TableSlotOption](/en/table/slot/#tableslotoption)                                   | -      |

### TableColumn

| Prop    | Description                                                    | Type                            | Default |
| ------- | -------------------------------------------------------------- | ------------------------------- | ------- |
| key     | Column field name                                              | string                          | -       |
| label   | Column title                                                   | string                          | -       |
| render  | Custom render function                                         | `(rowData, rowIndex) => VNode`  | -       |
| props   | Column props passed through to `n-data-table` (e.g. `width`, `minWidth`, `fixed`) | object                          | -       |
| display | Whether to display the column                                  | boolean                         | true    |
